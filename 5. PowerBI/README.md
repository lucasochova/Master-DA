# 5. PowerBI

Proyectos de Business Intelligence en Power BI.

- `proyecto 1- PIB_Deuda.pbix` — panel sobre PIB y deuda.
- `proyecto 2.pbix` — panel de ventas a partir de los datos en `datos proyecto 2/`.
- `datos proyecto 2/` — datos de clientes, productos, vendedores y pedidos usados en el proyecto 2.
